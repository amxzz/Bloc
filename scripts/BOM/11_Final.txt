3. ARSITEKTUR DATA & LOGIKA DATABASE SISTEM RESEP (FIREBASE / SQL)
--------------------------------------------------------------------------------

A. STRUKTUR HIERARKI RESEP:
   [MASTER BASE (MB-01 s/d MB-09)]
              |
              v
   [FLAVOR RECIPE FORMULATION]
              |
              +---> [CHARACTER COMPONENT (Puree, Paste, Extract, Swirl)]
              +---> [INCLUSIONS (Biscuit crumb, Brownie, Wafer, Praline)]
              |
              v
   [FINAL PRODUCTION RECIPE (Scaled to Batch Target: 3.000 g / 2.500 g)]

B. SCHEMA DATABASE RESEP:

   Table: master_bases
   - id                     : String (Primary Key)
   - code                   : String (MB-01 s/d MB-09)
   - name                   : String
   - base_type              : "DENSE" | "LIGHT_SORBET"
   - standard_batch_weight  : 3000 | 2500
   - target_fat             : Float
   - target_msnf            : Float
   - stabilizer_percent     : Float

   Table: recipes
   - id                     : String (Primary Key)
   - flavor_id              : String (Foreign Key)
   - master_base_id         : String (Foreign Key)
   - version                : String (e.g., "v1.0")
   - base_multiplier        : Float
   - is_active              : Boolean

   Table: ingredients
   - id                     : String (Primary Key)
   - name                   : String
   - fat_percent            : Float
   - msnf_percent           : Float
   - dry_solids_percent     : Float
   - pod_value              : Float
   - pac_value              : Float
   - allergen_milk          : Boolean
   - allergen_egg           : Boolean
   - allergen_gluten        : Boolean
   - allergen_soy           : Boolean
   - allergen_peanut        : Boolean
   - allergen_tree_nut      : Boolean
   - allergen_sesame        : Boolean

--------------------------------------------------------------------------------
4. ATURAN DINAMIS INHERITANCE ALERGEN (DYNAMIC ALLERGEN DECLARATION)
--------------------------------------------------------------------------------
Deklarasi Alergen Produk Akhir dihitung secara agregasi otomatis dari seluruh
bahan aktif yang terdaftar dalam recipe_ingredients:

[Raw Ingredients Allergen Flags] ---> [Recipe Ingredient Aggregation]
                                                |
                                                v
                                  [Final Product Allergen Set]

Contoh:
- Whole Milk (Milk: TRUE)
- Hazelnut Paste (Tree Nut: TRUE)
- Dark Chocolate (Soy: TRUE)
=> Final Allergen Output: "Contains: Milk, Tree Nuts, Soy"
