Standard Production Batch:
- Gelato / Dense Bases (01, 02, 03, 04, 06, 07, 08) : 3.000 g
- Sorbetto / Light Base (05 Mandarin Orange Blossom) : 2.500 g
================================================================================

--------------------------------------------------------------------------------
1. BUSINESS LOGIC & ARSITEKTUR AKTIVASI SEASONAL (POS & KITCHEN)
--------------------------------------------------------------------------------

A. STRUKTUR MASTER DATA DATABASE (FIREBASE / SQL):
   - flavor_id          : String (Unique Identifier)
   - season_name        : String (e.g., "Christmas", "Lebaran", "CNY", "Independence")
   - seasonal_status    : "ACTIVE" | "INACTIVE" | "SCHEDULED"
   - start_date         : ISO Date (YYYY-MM-DD)
   - end_date           : ISO Date (YYYY-MM-DD)
   - is_seasonal        : Boolean (TRUE)

B. ATURAN INTEGRASI POS CASHIER:
   - Ketersediaan rasa di POS Kasir diatur oleh logika:
     isAvailable = (seasonal_status === "ACTIVE")
                   && (currentDate >= start_date)
                   && (currentDate <= end_date)
                   && (showcase_tub_weight > minimum_sellable_weight)
   - Status INACTIVE / di luar rentang tanggal:
     * Otomatis tersembunyi dari grid menu kasir POS (tidak bisa dipilih).
     * Histori transaksi penjualan masa lalu tetap utuh (tidak rusak/hilang).
   - Tub Kosong (Empty):
     * Muncul indikator "Habis" / non-aktif di kasir.

C. ATURAN INTEGRASI KITCHEN & INVENTORY:
   - Master formula resep tetap tersimpan permanen di modul Manager -> Recipes.
   - Kitchen tetap dapat mengakses histori produksi batch terdahulu kapan saja.

--------------------------------------------------------------------------------
2. SOP PARAMETER PRODUKSI SEASONAL SERIES
--------------------------------------------------------------------------------
1. BALANCING     : Penimbangan presisi bahan dairy/sorbet, rempah, jam, dan pasta.
2. PASTEURIZING  : Base dipasteurisasi (kecuali komponen biskuit/swirl/jam).
3. RAPID COOLING : Penurunan suhu cepat ke 4°C dalam 10–15 menit.
4. AGING         : 4°C selama 4–12 jam.
5. CHURNING      : Suhu outlet -5°C s/d -9°C (durasi ±15–20 menit).
6. INCLUSION ADD : Biskuit (Gingerbread, Kastengel, Nastar) & ribbon swirl
                   dimasukkan di akhir churning atau folding penarikan pan.
7. BLAST FREEZER : Suhu -30°C s/d -40°C (durasi ±30–45 menit).
8. TEMPERING     : Suhu inti -11°C s/d -14°C (durasi ±15–30 menit).
9. SHOWCASE      : Suhu display -14°C s/d -16°C (monitoring real-time).
